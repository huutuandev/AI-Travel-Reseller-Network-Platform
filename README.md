# AI-Travel-Reseller-Network-Platform

## Yêu cầu

- Git
- Docker Desktop

## Chạy dự án

### 1. Clone project

git clone https://github.com/huutuandev/AI-Travel-Reseller-Network-Platform.git

### 2. Vào thư mục project

cd AI-Travel-Reseller-Network-Platform

### 3. Chạy Docker

docker compose up --build

### 4. Mở Frontend

Truy cập:

http://localhost:3000

## Dừng dự án

docker compose down

## Chạy lại

docker compose up
